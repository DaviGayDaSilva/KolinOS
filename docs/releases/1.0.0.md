# KolinOS 1.0.0 — "Corvo"

Distribuição Linux própria baseada em **Debian 13 (trixie)**, arquitetura
**arm64/aarch64**. Usa Debian como base e mantém compatibilidade com APT/DPKG,
acrescentando identidade, configuração e ferramentas próprias.

## Arquivos

| Arquivo | O que é |
|---|---|
| `kolinos-1.0.0-corvo-arm64.img.xz` | imagem de disco **inicializável por UEFI** (GPT: ESP FAT32 + root ext4), comprimida — comece por aqui |
| `kolinos-1.0.0-corvo-arm64.img` | a mesma imagem sem compressão (~1.4 GiB), para gravar direto |
| `kolinos-1.0.0-corvo-arm64.tar.xz` | root filesystem para **Termux/proot-distro**, chroot ou VM |
| `kolinos-1.0.0-corvo-arm64.iso` | ISO *carrier* com o rootfs + código-fonte (**não** é inicializável — ver aviso) |
| `kolinos-source-1.0.0-corvo.zip` | código-fonte completo do projeto |
| `SHA256SUMS` | checksums de todos os arquivos acima |
| `METADATA.txt` | proveniência do build (commit, epoch, suite) |

## Como gravar a imagem

```sh
xz -dk kolinos-1.0.0-corvo-arm64.img.xz
sudo dd if=kolinos-1.0.0-corvo-arm64.img of=/dev/sdX bs=4M status=progress conv=fsync
```

## Como usar no Termux

```sh
pkg install proot-distro
tar -xJf kolinos-1.0.0-corvo-arm64.tar.xz -C "$PREFIX/var/lib/proot-distro/installed-rootfs/kolinos"
proot-distro login kolinos
```

## Como emular no QEMU (sem hardware)

```sh
sudo apt install -y qemu-system-arm qemu-efi-aarch64 ipxe-qemu
bash scripts/host/qemu-boot.sh --image kolinos-1.0.0-corvo-arm64.img
```

Guia completo: [`docs/QEMU.md`](https://github.com/DaviGayDaSilva/KolinOS/blob/main/docs/QEMU.md).
Para Android: [`docs/LIMBO.md`](https://github.com/DaviGayDaSilva/KolinOS/blob/main/docs/LIMBO.md).

## Verificação

```sh
sha256sum -c SHA256SUMS
```

## Avisos honestos

- **A ISO não inicializa.** É um *carrier de dados* (rootfs + fonte +
  instalador), gerada com `xorriso -as mkisofs` **sem** El Torito. Não serve
  como CD de boot. Para inicializar, use o `.img`.
- **A imagem `.img` é UEFI arm64**, pensada para QEMU `virt`, VMs e placas
  arm64. **Não** é imagem de celular: um Android exige bootloader próprio e
  kernel com device tree (ver `docs/LIMITATIONS.md`).
- **Aceleração:** rodar arm64 em host x86_64 usa TCG (emulação por software).
  O boot leva minutos. Isso é esperado.
- **Proveniência:** os binários desta release (`.img`, `.img.xz`, `.iso`,
  `.tar.xz`) foram construídos no commit `be3dcb0`, com mirror Debian ao vivo
  (build **não** reproduzível byte a byte). O `METADATA.txt` registra isso. O
  ZIP de fontes foi regenerado a partir da árvore atual.
